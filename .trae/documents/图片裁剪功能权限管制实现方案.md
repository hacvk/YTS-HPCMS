# 图片裁剪功能权限管制实施计划

## 1. 实施目标

实现基于角色+栏目的双重图片裁剪权限控制，允许管理员配置：
- 哪些角色可以使用图片裁剪功能
- 哪些栏目允许使用图片裁剪功能

## 2. 实施步骤

### 步骤1：数据库修改

- **目标**：在 `sys_category` 表中添加 `allow_crop` 字段
- **SQL语句**：`ALTER TABLE sys_category ADD COLUMN allow_crop tinyint(1) NOT NULL DEFAULT 1 COMMENT '是否允许图片裁剪（0-不允许，1-允许）'`
- **验证方式**：检查数据库表结构

### 步骤2：完善权限检查逻辑

- **目标**：实现完整的 `hasPerm()` 方法
- **文件**：`app/Http/Controllers/Admin/AdminBaseController.php`
- **内容**：实现基于角色的权限检查逻辑
- **验证方式**：测试权限检查是否正常工作

### 步骤3：添加裁剪权限验证

- **目标**：在裁剪API中添加权限验证
- **文件**：`app/Http/Controllers/Admin/UploadController.php`
- **内容**：在 `crop()` 和 `uploadCrop()` 方法中添加 `requirePerm('admin:upload:crop')`
- **验证方式**：测试无权限用户是否无法访问裁剪功能

### 步骤4：栏目管理集成

- **目标**：在栏目管理中添加裁剪功能开关
- **文件1**：`app/Http/Controllers/Admin/CategoryController.php`
  - 实现 `add()` 和 `save()` 方法中对 `allow_crop` 字段的处理
- **文件2**：`app/Models/Category.php`
  - 添加 `allow_crop` 字段的模型定义
- **验证方式**：测试栏目保存时 `allow_crop` 字段是否正确保存

### 步骤5：前端界面修改

- **目标**：在栏目编辑界面添加裁剪功能开关
- **文件**：`views/admin/category/edit.latte`
- **内容**：添加裁剪功能开关的HTML和JavaScript
- **验证方式**：检查栏目编辑界面是否显示裁剪开关

## 3. 技术要点

- 权限标识：`admin:upload:crop`
- 数据库字段：`sys_category.allow_crop`
- 权限验证：`requirePerm('admin:upload:crop')`
- 前端控制：根据栏目设置动态显示裁剪按钮

## 4. 预期效果

- 管理员可以为不同角色分配图片裁剪权限
- 可以针对不同栏目开启/关闭裁剪功能
- 无权限用户无法使用裁剪功能
- 禁用裁剪的栏目中不显示裁剪按钮

## 5. 风险控制

- 数据库修改前备份数据
- 代码修改前做好版本控制
- 分步骤测试，确保每一步正常工作
- 保持向后兼容性，确保现有功能不受影响
